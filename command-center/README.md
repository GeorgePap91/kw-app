# KWAC Command Center · scripts

Κώδικας για το Google Sheet «KWAC Command Center» (project management, αντί για Notion).
**Δεν** ανήκει στην KW App: δεν μπαίνει στο `apps-script/` και δεν ανεβαίνει με clasp στο project της εφαρμογής.

## AutoDates.js · v1.1
Γράφει μόνο του τις ημερομηνίες που χρειάζεται το ταμπλό «Πρόοδος».

| Καρτέλα | Όταν… | …τότε |
|---|---|---|
| Στόχοι | τσεκάρεις «Έγινε» | «Ολοκληρώθηκε» = σήμερα (ξετσεκάρισμα → σβήνει) |
| Ιδέες | Κατάσταση = «Έτοιμο» | «Ολοκληρώθηκε» = σήμερα (άλλη κατάσταση → σβήνει) |
| Ιδέες | γράφεις νέα «Λειτουργία» | «Καταχωρήθηκε» = σήμερα, μόνο αν είναι κενό |
| QA | «✓ Πέρασε» ή «✗ Απέτυχε» | «Ημ. ελέγχου» = σήμερα, σε κάθε νέο έλεγχο («Εκκρεμεί» → σβήνει) |

### Εγκατάσταση (μία φορά, ~2 λεπτά)
> v1.1 (28/11/2026): η γραμμή 1 κάθε καρτέλας κρατά τα slicers, η κεφαλίδα είναι στη γραμμή 2 και τα δεδομένα ξεκινούν από τη 3.
1. Άνοιξε το workbook → **Επεκτάσεις → Apps Script**.
2. Σβήσε το περιεχόμενο του `Code.gs` (ή πρόσθεσε νέο αρχείο `AutoDates`) και επικόλλησε όλο το `AutoDates.js`.
3. **Αποθήκευση**. Τέλος. Δεν χρειάζεται trigger, deployment ή εξουσιοδότηση: το `onEdit` είναι simple trigger.

### Αναβάθμιση / επαναφορά
- Αναβάθμιση: επικόλληση της νέας έκδοσης πάνω από την παλιά, Αποθήκευση.
- Επαναφορά: επικόλληση της προηγούμενης έκδοσης από το GitHub, ή διαγραφή του αρχείου (τότε οι ημερομηνίες γράφονται με το χέρι, όπως πριν).

### Δοκιμή
1. Στόχοι: τσέκαρε έναν στόχο → εμφανίζεται η σημερινή ημερομηνία. Ξετσέκαρέ τον → σβήνει.
2. Ιδέες: βάλε «Έτοιμο» σε μια ιδέα → «Ολοκληρώθηκε» = σήμερα. Γράψε μια νέα λειτουργία σε κενή γραμμή → «Καταχωρήθηκε» = σήμερα.
3. QA: βάλε «✓ Πέρασε» → «Ημ. ελέγχου» = σήμερα.
4. Πρόοδος: το σημερινό τετράγωνο σκουραίνει.

### Όρια
- Simple trigger: έως 30″ ανά εκτέλεση. Εδώ διαβάζει και γράφει μόνο τις γραμμές που άλλαξαν, άρα χιλιοστά του δευτερολέπτου.
- Δεν τρέχει για αλλαγές από API ή άλλο script (π.χ. όταν γράφει ο Claude μέσω connector): τότε η ημερομηνία γράφεται μαζί με την αλλαγή.
- Η ημερομηνία γράφεται στη ζώνη ώρας του workbook (Europe/Athens), χωρίς ώρα.

Tests: `tests/command-center.test.mjs` (`npm test`).
